# القنصل — Travel Website
Static RTL Arabic website designed to run from Visual Studio Code and upload directly to Hostinger.

## Before launch
1. Replace `YOUR-DOMAIN.com` in all HTML files, `robots.txt`, and `sitemap.xml` with the real HTTPS domain.
2. Put the client's real hero video at `assets/video/hero.mp4`.
3. Replace SVG placeholder images in `assets/images/` with optimized WebP/AVIF images while keeping the same filenames or updating HTML.
4. Add the real company phone, WhatsApp, email, address and social profiles.
5. Connect the booking form to a real backend/API/payment provider. The current static demo does NOT process real flight reservations or payments.
6. Create a Google Search Console property and submit `/sitemap.xml`.
7. Add real Organization/TravelAgency structured-data details (address, phone, logo, sameAs) after the client's official data is confirmed.

## VS Code
Open this folder in VS Code and use Live Server for local preview.

## Hostinger
Upload the contents of this folder into `public_html/`.
